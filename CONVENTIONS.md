# Conventions

These coding conventions should be followed for a
pull-request to be considered and approved.

## Symbols

### Numeric Constants and Variables

All numeric constants should be in uppercase or the 
constant naming convention.

### Labels

Labels should be snake-case.

#### Note on Anonymous Labels

Only use anonymous labels sparingly, or use them when there
is a specific subroutine which only uses one control loop.
If that's the case, instead of using the cheap local label
syntax, use anonymous labels.

## Directives

All assembler directives should be written using snakecase.
